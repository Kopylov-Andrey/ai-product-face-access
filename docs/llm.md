# Опциональное LLM-пояснение для сотрудника

LLM добавлена только как **асинхронный слой объяснения уже принятого решения**. Она не входит в критический путь распознавания лица и не может изменить `ALLOW`, `DENY`, `MANUAL_REVIEW` или команду турникету.

## Сценарий использования

После `DENY` или `MANUAL_REVIEW` web-MVP может показать сотруднику короткое объяснение, почему проход сейчас не выполнен и что безопасно сделать дальше:

```text
deterministic decision engine
        ↓
CLOSED + audit event
        ↓
optional LLM explainer
        ↓
понятная причина + безопасное следующее действие
```

Если CAILA или модель недоступны, основной PoC продолжает работать без деградации решения доступа.

## Что передаётся в LLM

Только минимальный обезличенный безопасный контекст:

- итоговое решение;
- человекочитаемая категория причины;
- необходимость ручной проверки;
- режим деградации;
- рекомендуемое безопасное действие;
- `CLOSED`.

**Не передаются:** изображение лица, `employee_id`, embedding, match-score, пороги, top-K кандидаты, внутренние reason-коды и детали антиспуфинга.

## Safety-контракт

1. LLM вызывается только после детерминированного решения.
2. Для `ALLOW` пояснение через этот модуль намеренно запрещено.
3. Prompt запрещает предлагать `OPEN` при `CLOSED`, раскрывать защитные детали и придумывать новые причины.
4. Ответ LLM является только текстом: у модуля нет доступа к `TurnstileSimulator` и нет `command_id`.
5. Ошибка или timeout API не меняют решение и не блокируют основной интерфейс.
6. Текст предназначен для сотрудника и не должен повторять внутренние reason-коды или техническую диагностику.

## Локальный запуск

LLM-интеграция использует OpenAI-совместимый адаптер CAILA.

```powershell
python -m pip install -r requirements-llm.txt
$env:CAILA_API_KEY = (Get-Clipboard).Trim()
$env:CAILA_EXPLAINER_MODEL = "just-ai/google-gemini/gemini-3.5-flash"
python -m streamlit run web_app.py
```

`CAILA_BASE_URL` по умолчанию: `https://caila.io/api/adapters/openai`. Модель можно заменить через `CAILA_EXPLAINER_MODEL` без изменения кода.
