# Система контроля доступа с распознаванием лиц

Решение системно-продуктовой задачи по CV/ML для управления турникетом на основе распознавания лиц.

## Описание задачи

Система распознаёт лица людей, подходящих к турникету, и принимает решение об открытии прохода на основе сопоставления с базой сотрудников.

**Ключевой принцип безопасности:** в неопределённых или рискованных случаях турникет НЕ открывается автоматически.

## Статус

Продуктовое проектирование, архитектура и proof-of-concept разрабатываются в рамках тайм-боксированного задания.

## Локальная проверка

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python scripts/verify.py
```

## Структура репозитория

- `docs/product.md` — продуктовые решения
- `docs/architecture.md` — архитектурные решения и детали
- `docs/risks-and-ops.md` — риски, режимы отказа, эксплуатация
- `app/` — минимальный proof-of-concept
- `tests/` — тесты поведения и инвариантов безопасности
- `scripts/verify.py` — единая кросс-платформенная проверка перед коммитом
- `.github/workflows/ci.yml` — воспроизводимость на CI

## Примечание

Не коммитить `.env`, API-ключи или учётные данные.
